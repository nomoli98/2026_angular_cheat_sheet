Dark mode (theme toggle)

Bootstrap 5.3 does the work: one attribute on <html>, data-bs-theme="dark", and every Bootstrap color switches. Full guide: THEME.md.

Right now

theme.theme() = {{ theme.theme() }}, @if (theme.followsSystem()) { following your system setting (nothing saved). } @else { your choice, saved in localStorage. }

1. ThemeService

Keeps the theme in a signal. An effect() writes it on <html> every time it changes. No choice saved yet → it follows prefers-color-scheme (the OS setting), and keeps following it if the OS changes.

2. The switch

A Bootstrap form-switch in the navbar, next to the auth toggle.

3. No white flash on load

Angular starts a few milliseconds after the page is drawn. A tiny script in index.html sets the theme before, so a dark-mode user never sees a white flash.
