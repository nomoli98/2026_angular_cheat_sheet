Bootstrap

How to add Bootstrap (CSS only) to an Angular project, and how this cheat sheet uses it. Full guide: BOOTSTRAP.md · Bootstrap 5.3 docs.

1. Install

That's it for the CSS. No @popperjs/core, no @angular/localize: those are only needed for Bootstrap's JavaScript (step 7).

2. Load the CSS

In angular.json (projects > your-project > architect > build > options), add Bootstrap before your own styles.css. Order matters: the last file wins, so your styles can override Bootstrap. Or import it at the top of styles.css instead.

⚠️ Restart ng serve after changing angular.json: it isn't hot-reloaded.

3. Use the classes

Nothing to import in the component: the CSS is global, so the classes work in every template.

4. Forms

<label> → form-label · <input>, <textarea> → form-control · <select> → form-select · checkbox / radio → wrapper form-check, input form-check-input, label form-check-label.

5. Form validation with Angular

Bootstrap shows an input in red with is-invalid and shows the message in invalid-feedback. Angular decides when, with a class binding.

  • [class.is-invalid]="condition" adds the class only while the condition is true. No NgClass needed.
  • .invalid-feedback is hidden unless the element right before it is .is-invalid. For radios and checkboxes, force it: class="invalid-feedback d-block".

Same idea with all three kinds of form: see the form pages (/form/...).

6. Customise the look

Bootstrap 5.3 exposes its colours and sizes as CSS variables (--bs-primary, --bs-border-radius, --bs-body-bg…). Use them in your CSS, or override them in styles.css (loaded after Bootstrap). Dark mode = data-bs-theme="dark" on <html> (see the Dark mode page).

To change the brand colours everywhere ($primary…), you need the Sass version: rename styles.css to styles.scss, remove the .min.css from angular.json and write $primary: #6f42c1; @import 'bootstrap/scss/bootstrap';. Only if you really need it.

7. (Optional) The JavaScript parts

Dropdowns, modals, collapse, tooltips… need JavaScript. Two ways:

  • a. ng-bootstrap (recommended in Angular): installs ng-bootstrap plus @popperjs/core and @angular/localize. Then import what you need (e.g. NgbDropdownModule) in the component's imports.
  • b. Bootstrap's own JS bundle in angular.json: the data-bs-toggle="..." attributes then work. Simpler, but it touches the DOM behind Angular's back.

This cheat sheet uses CSS only.

8. How this cheat sheet uses it

Rule: few classes in the templates, the rest in src/styles.css.

  • app.html has the navbar and <main class="container py-4"> once, so no page needs its own container.
  • Each section of a page is a <section class="card card-body mb-3">.
  • Plain <button>, <input>, <select> get a Bootstrap look from styles.css: buttons only with no class (button:not([class])), inputs unless they already have a Bootstrap class (input:not(.form-control)), because Angular adds ng-valid, ng-touched… to them.
  • h2 / h3 / h4 inside <main> are styled in styles.css.
  • Form pages use the real Bootstrap form classes, because that's worth having as an example.

Gotchas

  • input-group is a Bootstrap class (puts its children on one row). Don't use it for your own "label + input", use mb-3.
  • Same for form, card, container, row, col, active, disabled… pick other names for your own classes.
  • Component styles (styleUrl) are scoped: they can't restyle Bootstrap elsewhere. Global overrides go in src/styles.css.
  • Changed angular.json and nothing happened? Restart ng serve.
