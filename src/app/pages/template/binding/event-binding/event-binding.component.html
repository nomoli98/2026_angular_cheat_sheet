Event binding

Native events

Using native event (click, keyup, keydown, mouseover, onchange,... See https://developer.mozilla.org/en-US/docs/Web/API/Element#events for more) we can link elements in the DOM and do simple changes.

We can put the logic in the event ("(click) = "value.set('New value')") like here:

{{value()}}

Or we can reference methods in the .ts file

{{pressedKey()}}
