Conditions

@If, @else

@if (firstOption()) {

This is the first option

} @else if (secondOption()) {

This is the second option

} @else {

This is none

}

You cannot show both options, because if the first @if is true, that will be the one showed.

@switch

@switch (switchOptions) { @case ('A') {

Show A

} @case ('B') {

Show B

} @default {

Show default

} }
