Loops

@For

    @for (item of items; track item.id) {
  • {{ item.name }}
    • }

IMPORTANT : the track in the parameter in the loops. You can track a unique property of your items OR the $index of the item in the list or any of the other contextual variables available (https://angular.dev/guide/templates/control-flow#contextual-variables-in-for-blocks)

Which one to pick:

  • track item.id: the default. Use it whenever the items have a unique id.
  • track item: for a list of strings or numbers with no duplicates.
  • track $index: only for a list that never gets items added, removed or re-ordered. Otherwise Angular re-uses the wrong DOM elements (inputs keep the old text, animations break).
    @for (item of items; track $index) {
  • {{ item.name }}
    • }
