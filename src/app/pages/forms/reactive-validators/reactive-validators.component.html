Reactive Forms · Validators

Every rule lives in the .ts, next to the FormControl. Type in the fields: the errors line shows what Angular sees. Full guide: REACTIVE_VALIDATORS.md.

3. Cross-field validator

A control's validator can't see the other controls. Put the validator on the group: the error lands on the group, so read it with crossForm.hasError('fieldsMismatch').

@let confirm = crossForm.controls.confirmPassword; @let mismatch = confirm.touched && crossForm.hasError('fieldsMismatch');
@if (confirm.touched && confirm.hasError('required')) {
Please confirm the password
} @else if (mismatch) {
Passwords don't match
}
group errors: {{ crossForm.errors | json }}

4. Async validator

Returns an Observable. It only runs when the sync validators pass, and pending is true while it waits. Needs the fake API (npm run dev). Try bob@email.bob.

@let email = asyncForm.controls.email; @if (email.pending) {
Checking the email...
} @if (email.touched) { @if (email.hasError('required')) {
Email is required
} @if (email.hasError('email')) {
Not a valid email
} @if (email.hasError('emailTaken')) {
This email is already taken
} }
status: {{ email.status }} · errors: {{ email.errors | json }}
