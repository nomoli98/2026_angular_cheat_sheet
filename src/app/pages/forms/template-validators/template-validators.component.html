Template Forms · Validators

Every rule is an HTML attribute on the input. A custom rule needs a directive. Type in the fields: the errors line shows what Angular sees. Full guide: TEMPLATE_VALIDATORS.md.

1. Built-in attributes

required, minlength, maxlength, email, pattern, and min / max on type="number". On a checkbox, required means "must be checked".

@if (nameCtrl.touched) { @if (nameCtrl.errors?.['required']) {
Name is required
} @if (nameCtrl.errors?.['minlength']) {
At least {{ nameCtrl.errors?.['minlength'].requiredLength }} characters
} }
errors: {{ nameCtrl.errors | json }}
@if (heightCtrl.touched) { @if (heightCtrl.errors?.['min']) {
Minimum 50 cm
} @if (heightCtrl.errors?.['max']) {
Maximum 275 cm
} }
errors: {{ heightCtrl.errors | json }}
@if (termsCtrl.touched && termsCtrl.errors?.['required']) {
You must accept the terms
}
errors: {{ termsCtrl.errors | json }}

2. Custom validator (directive)

A directive that implements Validator and registers itself in NG_VALIDATORS. Parameters are directive inputs: appBirthdate [minAge]="18" [maxAge]="120".

@if (passwordCtrl.touched) { @if (passwordCtrl.errors?.['required']) {
Password is required
} @if (passwordCtrl.errors?.['strongPassword']) {
8+ characters, an uppercase, a lowercase and a digit
} }
errors: {{ passwordCtrl.errors | json }}
@if (birthdateCtrl.touched) { @if (birthdateCtrl.errors?.['required']) {
Birthdate is required
} @if (birthdateCtrl.errors?.['birthdate']) {
You must be 18 to 120 years old
} }
errors: {{ birthdateCtrl.errors | json }}

3. Cross-field validator

Put the directive on the <form>: ngForm picks it up and gives it the whole group. The error lands on the form: crossForm.hasError('fieldsMismatch').

@if (confirmCtrl.touched && confirmCtrl.errors?.['required']) {
Please confirm the password
} @else if (confirmCtrl.touched && crossForm.hasError('fieldsMismatch')) {
Passwords don't match
}
form errors: {{ crossForm.errors | json }}

4. Async validator (directive)

Same as a custom directive, but registered in NG_ASYNC_VALIDATORS and validate() returns an Observable. It reuses the reactive emailTakenValidator(). Needs the fake API (npm run dev). Try bob@email.bob.

@if (emailCtrl.pending) {
Checking the email...
} @if (emailCtrl.touched) { @if (emailCtrl.errors?.['required']) {
Email is required
} @if (emailCtrl.errors?.['email']) {
Not a valid email
} @if (emailCtrl.errors?.['emailTaken']) {
This email is already taken
} }
status: {{ emailCtrl.status }} · errors: {{ emailCtrl.errors | json }}
