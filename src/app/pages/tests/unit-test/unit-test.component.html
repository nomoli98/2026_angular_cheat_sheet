Unit tests (Vitest)

A unit test checks one small piece (a component, a service) on its own, without opening a browser. Each demo below has its test in the .spec.ts tab. Full guide: UNIT_TEST.md.

Run the tests

1. Component basics

Create the component, read the HTML, click a button, check the result.

2. Inputs and outputs

Give a value to an input() with setInput(), listen to an output() with a spy.

3. A service

A basic fake login / register service (no server, no token). Get it with TestBed.inject(), call its methods, check what they return.
