E2E tests (Playwright)

An end-to-end (e2e) test opens your real app in a real browser and uses it like a user: go to a page, type, click, check what's on screen. Full guide: E2E_TEST.md.

The page we test

The same login form as on the unit test page. Playwright opens this page, fills the form and checks the result. Try bob@email.bob / BobIsTheBest99#.
