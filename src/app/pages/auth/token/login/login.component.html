Login / Logout (token)

Same page as Login (bcrypt), but with TokenAuthController: the browser sends email + password to the auth server (POST /token/login). The server runs bcrypt.compare and answers a signed JWT. The browser never sees the hash; it keeps the token in localStorage.

Log in, then refresh the page: you're still logged in (the token is saved). Separate from the normal login (the navbar). Needs the auth server: npm run dev.
