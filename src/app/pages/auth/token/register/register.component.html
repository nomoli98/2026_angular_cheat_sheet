Register (token)

Same page as Register (bcrypt), but calls TokenAuthController.register(request) → POST /token/register on the auth server (localhost:3001). The server checks the email, hashes the password with bcrypt, stores it in securePeople and answers a token: you're logged in (token version), even after a refresh.

Needs the auth server: npm run dev starts it (or npm run api:auth). Remove test accounts with npm run api:reset.
