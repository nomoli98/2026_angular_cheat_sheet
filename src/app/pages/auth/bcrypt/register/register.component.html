Register (bcrypt)

Same page as Register, but calls BcryptAuthController.register(request): the service checks the email is free (GET /securePeople?email=...), hashes the password with bcrypt, then stores the hash (POST /securePeople). The new user is logged in to the bcrypt version only (the navbar shows the normal one).

Open fake-api/db.json after you register: in securePeople your password looks like $2b$10$.... Remove test accounts with npm run api:reset.
