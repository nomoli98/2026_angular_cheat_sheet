Login / Logout (bcrypt)

Same page as Login, but with BcryptAuthController: the service gets the user from /securePeople, then bcrypt.compare(typedPassword, storedHash) says if the password is right. The password is never stored, never compared as plain text.

This login is separate from the normal one (the navbar) and lives in memory: a refresh forgets it. Notice the short wait when you log in: bcrypt is slow on purpose.
