Fake API (json-server)

What is it?

A pretend backend so you can practise HttpClient and CRUD without writing a server. json-server reads one JSON file and turns every list in it into a REST API: "people": [...] becomes http://localhost:3000/people. 

Angular (localhost:4200) ──HTTP──▶ json-server (localhost:3000) ◀──reads/writes──▶ db.json

It's a real HTTP server: POST, PUT, PATCH and DELETE really change db.json. It checks nothing (no login, no validation): that's why this repo checks permissions in the controllers.

1. Install it

Keep the @0.17.4: a plain npm install json-server gives the 1.0 beta, which works differently (string ids, other query params). concurrently runs the API and Angular with one command.

2. Create the data file

One key per resource, each one a list of objects with an id. Keep a copy (db.seed.json) to reset the data after your tests.

3. Add the npm scripts, then run

--watch reloads when you edit db.json by hand. Open http://localhost:3000/people in the browser: you should see the JSON.

5. Call it from Angular

Put the URL in the environment file, turn on HttpClient once, then use it in a service. It returns an Observable: nothing is sent until someone subscribes (or calls firstValueFrom(), like the controllers do).

In this repo

  • npm run dev: installs json-server if missing, then starts the API + Angular
  • npm run api:reset: puts the 10 original people back
  • npm run api:slow: every answer waits 1 s, to see loading states
