Update a user fully (PUT)

Calls UserController.updateFully(id, request) → PUT /people/:id. PUT replaces the whole user: every field must be sent, even the ones that do not change. Admin only (a simple user → forbidden). Use Load current values to fill the form first (the password is never sent back, so type a new one).

This really changes fake-api/db.json. Undo everything with npm run api:reset.
