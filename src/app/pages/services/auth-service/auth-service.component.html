1. AuthService

Remembers who is logged in in a signal, currentUser. login() checks the email + password against the API and fills it, logout() empties it. Everything else (controllers, guard, toggle) just reads currentUser().

2. The guard

A function the router calls before opening a page. Logged in → true, the page opens. Not logged in → it returns another URL (this page), with ?returnUrl= to come back later.

3. The toggle

A demo helper, like a theme switch: on = real login as Bob (admin) through the API, off = logout. Saved in localStorage, and the app logs in again on start if it was on.
